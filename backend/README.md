# ROLLU · 롤루 자동 활동 집계 웹사이트 (프로토타입)

**이 저장소는 서버에서 실제로 실행할 수 있는 웹 애플리케이션 소스코드입니다.** 정적 HTML만 더블클릭해서 여는 사이트가 아니며, 라이엇 API 키·서버·HTTPS 도메인 준비 전에는 실시간 자동 수집이 작동하지 않습니다.

## 기능

- 모임원이 처음 한 번 `게임 이름#태그` + 모임 초대 코드를 입력하고 기록 공개에 동의
- 회원 전용 열람 코드 보호 (미설정 시 가입 초대 코드로 열람)
- 운영진의 가입 승인 (RSO 계정 소유권 인증 대신 수동 확인)
- 승인된 회원을 대상으로 Riot Account-V1 → Match-V5 조회, 일정 간격 자동 동기화
- 개인 플레이와 **모임 회원 간 같은 경기 참여**를 구별한 활동 대시보드
- 이번 달 자동 집계, 회원 간 솔로/듀오·자유랭크 동반 경기, 운영진 이전 월 기록 조회(기본 18개월)
- ‘활발’, ‘가끔 참여’, ‘개인 활동만’, ‘게임 기록 없음’, ‘조회 확인 필요’ 별도 표시
- 비공개 사용자 설정 게임 공개에 대한 **별도 옵트인** 및 철회/삭제
- 운영진의 회원 승인·탈퇴 처리·재활성화·영구 삭제, 수집 실행, 가입자 본인 데이터 삭제
- 서버 저장 데이터베이스(SQLite), 모바일/PC 대응 UI

## 실행법: 로컬 체험

1. 이 압축파일을 풀고 Docker Desktop을 실행합니다.
2. `.env.example` 파일을 `.env`로 복사합니다.
3. `.env`의 `ADMIN_PASSWORD`, `JOIN_CODE`를 **서로 다른 강한 비밀번호**로 바꾸세요. `VIEW_CODE`를 별도 지정하지 않으면 `JOIN_CODE`로 회원 페이지를 열람합니다.
4. `DEMO_MODE=1`을 유지하고 터미널에서 `docker compose up --build -d`를 실행합니다.
5. 브라우저에서 `http://localhost:8000`을 엽니다. *가상 데이터*만 보입니다.
6. 종료: `docker compose down`. 모든 기록을 지우려면 `docker compose down -v` (주의: DB 삭제).

### Docker 없이 실행하기 (Python 3.11+)

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # Windows: copy .env.example .env
# .env에서 비밀번호/초대 코드 교체
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 실전 자동 수집 시작하기

1. https://developer.riotgames.com 에서 Riot API 키를 발급받습니다. **개발 키는 매 24시간 비활성화되므로 지속 운영에는 적합하지 않습니다.** 작은 사설 모임이면 Personal API 키를 신청하고, 서비스 규모/목적에 맞는 키를 확인합니다.
2. `.env`의 `DEMO_MODE=0`, `RIOT_API_KEY=...`, `ADMIN_PASSWORD=...`, `JOIN_CODE=...`를 설정합니다. API 키는 절대 소스·브라우저 JS·GitHub에 넣지 마세요.
3. 호스팅 서버 + **HTTPS 도메인**에 배포합니다. HTTPS 프록시를 사용하는 서비스에서 `.env`의 `COOKIE_SECURE=1`로 바꿉니다. 리버스 프록시에서는 Host 헤더를 정상 전달해야 합니다.
4. 회원마다 등록 동의를 받고, 운영진이 가입한 실제 회원과 Riot 계정의 소유권을 확인 후 승인합니다. 공개 전적 자동 수집은 그 시점부터 실행됩니다.
5. 디스코드 채널에 사이트 URL을 공유합니다. 단순 링크만 있으면 PC/모바일 모두 브라우저에서 볼 수 있습니다.

> **주의:** 가입 폼은 Riot ID를 *조회*할 뿐 ID 소유권을 자동으로 증명하지 않습니다. 진짜 라이엇 계정 연동 로그인(RSO)은 Riot의 별도 Production 자격 및 승인이 있어야 합니다. 운영진의 수동 확인 없이 계정을 승인하면 타인이 임의 계정을 등록할 가능성이 있습니다.

## 전적 판정의 정확한 한계

- Riot 공식 Match-V5의 **420은 ‘솔로·듀오’ 단일 큐**입니다. 이 데이터만으로 ‘혼자 신청한 솔랭’과 ‘듀오로 신청한 랭크’를 완벽하게 구분하지 못합니다. 이 앱은 별도 `duo_observed` 참고 지표만 계산합니다. 동일 팀에서 매칭된 회원이 곧 사전 약속된 듀오라는 뜻은 아닙니다.
- 같은 경기·팀에 모임원이 나타났다는 사실이 실제 모임 모집에 참여한 것을 100% 보장하지 않습니다. 표시 이름을 **모임 참여 추정 기록**으로 이해해 주세요. 타 팀이라도 사용자 설정 게임(내전)에서 같은 경기에 있었다면 함께 기록됩니다.
- Riot API가 제공하지 않는 **사용자 설정 경기/비공개 내전**, 다른 게임으로 만든 자체 이벤트, 참가자 명단은 자동으로 만들 수 없습니다. 이 코드에서는 `queueId=0` 게임이 공식 API에 접근 가능하고 **각 회원이 별도로 공개에 동의한 경우에 한해** 수집할 수 있습니다. API에서 나오지 않는 내전을 100% 자동 추적하려면 추가로 허용된 로그/별도 서비스 연동이 필요합니다.
- 라이엇은 공식 실력 랭킹과 혼동되는 MMR/ELO 계산 도구를 금지합니다. 이 앱은 *참여 건수* 랭킹이지 실력 MMR이 아닙니다.
- API 오류·키 만료·동기화 실패 회원은 ‘유령회원’으로 단정하지 않고 ‘조회 확인 필요’로 표시합니다. 전체 게임을 0판 플레이한 경우도 게임/모임 활동의 직접 증거가 아닐 수 있습니다.
- 회원이 재등록/변경하거나, 데이터가 오래된 매치가 아예 API에 없는 경우, 월별 통계가 불완전할 수 있습니다. 실제 운영 전 초과 기록·미수집 감지를 더 보강하세요.

## 보안·운영 주의

- 모임원 nickname, Riot ID, 공유 전적은 **열람 코드를 아는 모두에게 노출됩니다.** 비밀 코드를 외부에 공유하지 마세요. 운영에 앞서 공개 범위, 동의 문구, 개인정보 처리 방침, 삭제 요청 방법을 정하세요. 보다 강한 신원 인증이 필요하다면 회원 개별 로그인/RSO를 추가해야 합니다.
- 이용자별 본인 수정/삭제 토큰은 발급 시 *한 번만* 표시하며 SHA-256 해시만 DB에 저장합니다. 분실 시 운영진이 삭제하거나 안전한 본인 확인 절차를 추가해야 합니다.
- 데이터는 단일 프로세스 SQLite를 전제로 설계했습니다. 프로덕션에서 Uvicorn을 2개 이상 실행하면 주기 동기화가 중복될 수 있습니다. 사용자/트래픽 규모가 커지면 PostgreSQL + 독립 작업 큐 + OAuth/RSO + 모니터링으로 이전하세요.
- API 호출 간격은 기본 1.4초, 429 `Retry-After` 반영. 실제 Riot 키별 제한이 달라질 수 있으므로 모니터링 필수.
- 트래픽/가입 폼 남용 방지(프록시 IP별 제한·CAPTCHA), 백업, HTTPS, 접근 로깅 제한, 계정 소유 검증, 복구/마이그레이션 계획 등은 실서비스 공개 전 보완해야 합니다.

## 기술 구성

- Backend: Python FastAPI, SQLite, asyncio 스케줄러, httpx + Riot API
- Frontend: HTML/CSS/vanilla JS (모바일 반응형)
- 배포: Dockerfile / Docker Compose, 단일 인스턴스 / 영속 볼륨
- 테스트: `pytest -q` (개발 환경에서 pytest 설치 필요)

## v1.1 추가: 매달 1일 갱신 / 운영진 월별 기록 / 탈퇴 처리

- **매월 1일 00:00(Asia/Seoul)**부터 새 달 통계를 **그달 경기만**으로 계산합니다. 기록이 없어 0판으로 표시되어도 실제 지난달 전적은 DB에 남아 있습니다. 자정에 모든 데이터가 실시간 확정되는 방식은 아닙니다. 기본 수집 주기는 3시간이며, 서버가 실행 중이고 유효한 API 키가 있어야 갱신됩니다.
- 운영진 로그인 → **월별 기록 조회**에서 지난달/이전 달을 볼 수 있습니다. 현재 공개 페이지는 **이번 달만 열람**합니다. `HISTORY_MONTHS` 기본 18개월(현재 달 + 지난 18개월)로 보관·조회 가능하며, 데이터 수집을 시작하기 전 과거 기록을 모두 복구할 수 있다는 뜻은 아닙니다.
- 운영진 **탈퇴 처리**는 회원을 활동 회원 목록과 자동 수집 대상에서 제외하고, 본인이 공개에 동의한 이미 수집된 과거 기록은 정해진 기간 보관합니다. 재가입 복구도 가능합니다.
- **영구 삭제**는 별도 작업입니다. 모임원 본인의 삭제 요청이나 개인정보 파기 필요 시 회원 및 해당 개인과 연결된 전적을 삭제합니다. 이 경우 과거 월 통계에서도 해당 회원이 제거됩니다.
- `queueId=420`은 솔로/듀오 공통 큐, `queueId=440`은 자유랭크입니다. 회원끼리 **같은 경기에 같은 팀으로 나타난 기록**을 `회원끼리 솔·듀` / `회원끼리 자랭`으로 집계합니다. **사전에 파티를 맺어 함께 큐를 돌렸는지는 증명할 수 없습니다.** 같은 팀으로 우연히 매칭된 사례가 포함될 수 있습니다.
- 관리자 전용 월별 데이터와 회원별 함께한 대상(닉네임·게임 수)을 제공합니다. 미활동·유령회원 판정을 자동 확정하지 않고, API 조회 실패 또는 신규 가입/수집 공백을 별도 주의 대상으로 보아야 합니다.

### API 연동 시 확인할 것

1. **개발/테스트:** Riot Developer Portal(`https://developer.riotgames.com/`) 로그인 → 개발 키 → `.env`의 `RIOT_API_KEY`에 비공개로 입력. 개발 키는 24시간 후 비활성화되므로 자동 운영용으로 쓰지 마세요.
2. **소규모 비공개 모임:** 프로젝트 등록을 통해 Personal Key를 신청하고, 롤루 서비스가 해당 정책에 적합한지 개발자 포털에서 확인하세요. 링크를 전체 공개하는 서비스라면 Production Key가 필요할 수 있습니다.
3. **서버:** `.env`의 `DEMO_MODE=0`, 강한 `ADMIN_PASSWORD`, `JOIN_CODE`, `VIEW_CODE` 설정. 자체 도메인 HTTPS에서 `COOKIE_SECURE=1` 사용.
4. **회원 수집:** 모든 참가자는 `게임이름#태그`와 동의를 입력 → 운영진이 신원 확인 후 승인 → `Asia` Account-V1로 PUUID를 조회, Match-V5로 경기 IDs 및 팀을 조회.
5. **확인:** 자랭 1판, 솔·듀 1판을 실제 롤루 회원들과 플레이 후 3시간 이내 수집 여부와 `shared_flex`, `shared_solo_duo` 집계를 점검하세요. 데이터 누락, 호출 제한(429), 403(키/권한) 등이 있으면 먼저 해결해야 합니다.

**주의:** 이 프로젝트는 실행 코드/모의 테스트를 제공하지만, **실제 Riot API 키·운영 도메인·회원 데이터로 테스트하지 않았습니다.** 회원 식별·권한 검증의 한계, 반복 로그인 시도 방어/모니터링/백업 등 공개 운영 전에 추가 보안 검토가 필요합니다. 본문 예시 값이나 `.env`를 그대로 배포하지 마세요.


## v1.2: 화면 전환 및 오프라인 미리보기 사용 안내

- 화면 상단의 **홈 / 랭킹 / 회원 활동 / 운영 안내**를 누르면 해당 화면으로 전환됩니다. 모바일 화면에도 메뉴를 표시합니다. 브라우저 뒤로 가기로 이전 화면으로 이동할 수 있습니다.
- `ROLLU_오프라인_미리보기.html`은 **디자인과 조회 화면 체험용 단일 HTML**입니다. 홈·랭킹·회원 활동·운영 안내 전환과 게임 모드 필터, 가상 월간 기록 조회가 가능합니다.
- **오프라인 HTML에서 회원 등록, 탈퇴, 전적 수집, 데이터 저장은 불가능합니다.** 해당 버튼은 의도적으로 비활성화되어 있습니다. 
- 실제 기능은 `.env`를 설정하고 `docker compose up --build -d`로 서버를 띄운 후 `http://localhost:8000`에서 시험해야 합니다. Riot API 자동 수집은 `DEMO_MODE=0` 및 실제 키·회원 등록·승인·정상 동기화가 추가로 필요합니다.
