HOW IT WORKS

처음 한 번 등록, 그다음은 자동으로.

01

라이엇 ID 등록

회원이 Riot ID, 태그, 표시 이름을 입력하고 게임 기록 수집·공개에 동의해요.

02

운영진 확인

운영진이 실제 롤루 회원과 연결되는 계정인지 확인하고 등록을 승인해요.

03

정기 전적 업데이트

서버가 Riot API를 통해 새 경기를 수집해 순위와 활동 상태를 갱신해요.

※ 비공개 내전은 별도의 명시적 동의가 필요하며, Riot API에서 실제 조회 가능한 경기만 반영됩니다. 비공개 전적의 완전 자동 수집은 보장되지 않아요.
