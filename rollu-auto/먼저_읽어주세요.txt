ROLLU 모임 활동 자동화 사이트 v1.2

[1] 화면 먼저 보기
  - ROLLU_오프라인_미리보기.html 파일을 크롬/엣지로 열기
  - 상단 '홈 / 랭킹 / 회원 활동 / 운영 안내'를 눌러 화면 전환
  - 랭킹 모드 필터와 운영진의 과거 월 기록 조회는 가상 데이터로 체험 가능
  - 모바일에서도 상단 메뉴 표시
  - 이 파일은 화면 체험용! 회원 가입, 탈퇴/삭제, 데이터 저장, 자동 수집은 동작하지 않음

[2] 실제 사이트 실행
  - .env.example을 .env로 복사하여 비밀번호·코드 설정
  - Docker Desktop을 설치/실행하고 이 폴더에서 docker compose up --build -d
  - 브라우저에서 http://localhost:8000 접속
  - 라이엇 API 키가 없어도 DEMO_MODE=1이면 서버 기능의 일부를 가상 데이터로 점검 가능
  - 실제 전적 수집은 DEMO_MODE=0 + 유효한 RIOT_API_KEY + 회원 등록·승인이 필요

[3] 주의
  - 실제 Riot API 조회 / 배포 환경은 검증되지 않음
  - 키와 운영진 비밀번호를 공개하지 말 것
  - 함께한 자랭·솔로/듀오 데이터는 같은 팀 참가 기록이지 사전 파티 확정 기록이 아님

기술 구성, Docker·Python 실행법과 운영·보안 주의는 README.md 참조.
